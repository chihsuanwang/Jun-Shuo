# 歷史資料匯入工具

把 `2025桂圓銷售_整理版.xlsx` 的 2024 / 2025 舊資料匯進 `guiyuan_ledger.db`。

## 流程

### 1. 產出對照表(這支已完成)

```
python build_mapping.py
```

- 讀 `../../2025桂圓銷售_整理版.xlsx`(可用參數指定其他路徑)
- 產出 `../../匯入對照表.xlsx`,含分頁:
  - **商品對照** — 整理版每個「品項＋規格」→ 系統 SKU
  - **客戶對照** — 整理版每個客戶原字串 → 系統客戶 / 新建 / 合併
  - **通路對照** — 來源+物流線索 → 銷售管道
  - **批次對照** — 每產季的批次代碼、產出量、單位成本、製造日
  - **價格參考** — 唯讀,過去成交價分佈
  - **說明** — 各欄怎麼填
- 黃底(★開頭)欄位由郡碩農創填;其餘為系統建議值,可直接改。

### 2. 郡碩農創填對照表

只有他們知道「劉麗華(基隆)與(宜蘭)是不是同一人」「#26 是哪個規格」「每批成本多少」。

### 3. 匯入(第二支腳本,待對照表填好後製作)

`匯入歷史.py` 會:
- 依對照表把整理版每一列 → 一張訂單 + 明細寫進資料庫
- 對不上的丟 `review_queue` + 產 `匯入待確認.csv`
- 整理版「資料檢核」有標記的 23 筆不匯入,另列清單
- 產對帳報告(各產季筆數、總營收 vs 原檔)
