# 報稅參考 · 郡碩農創申報現況

> **這套系統不做報稅。** 2026-09 與田家易確認:他目前無會計背景,系統不追求產出 403 / 營所稅
> 可用的申報數字,「B 層報稅支援」這個目標已整個取消(見 [開發路線.md](開發路線.md) 回合 12 說明)。
> 稅額 / 可扣抵 / 憑證類型 / 應稅免稅等欄位已從進貨、營運費用、商品目錄的畫面上拿掉;
> 對應的資料庫欄位還留著但沒有任何畫面會去寫它,純粹是歷史包袱,以後也不會再接起來。
>
> 這份文件現在只是**歷史背景 / 參考資料**——把郡碩實際報稅的現況留底,將來如果真的找記帳士 /
> 會計師處理報稅,可以直接把這份丟給對方看,省得重新問一輪。**不是這套系統的功能說明。**
>
> 來源:郡碩 2026-09 提供的兩份報表(114 年度營所稅結算申報、115 年 5–6 月 403)。

## 五、對系統設計的意涵(已取消,僅留紀錄)

> 以下是 v2 改造初期(回合 1)規劃「B 層報稅支援」時寫的設計筆記。2026-09 已確認不做,
> 底下內容不再是開發方向,純粹留著讓看到舊筆記的人知道當初想過什麼、為什麼後來不做了。

- ~~系統要能切曆年 / 403 雙月期~~ → 系統只有「產季」視角,不會再加曆年 / 403 期間切換。
- ~~免稅 / 應稅 / 零稅率分類~~ → `product_group.tax_class` 欄位還在資料庫裡但沒有畫面會寫入,
  也不會再去問國稅局怎麼認定。
- ~~兼營比例年度調整~~、~~累積留抵稅額追蹤~~、~~年度損益表對應申報書行號~~ → 都不做。
- 「帳載 → 稅務調整」這件事,將來如果要報稅,還是要交給真正報稅的人(記帳士 / 會計師)自己處理,
  這套系統不會、也不打算產出報稅可用的數字。
