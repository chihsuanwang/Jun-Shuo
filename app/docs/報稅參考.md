## 五、對系統設計的意涵

- 系統目前只有「產季」視角 → B 層要能切 **曆年 / 403 雙月期**(`queries.season_of()` 之外要有期間 helper)。
- **免稅 / 應稅 / 零稅率** 分類:`product_group.tax_class` 欄位已備好(預設「待確認」),
  等國稅局南投分局確認 龍眼鮮果 / 龍眼乾 / 龍眼肉 / 蜂蜜 各自的認定。
- **兼營比例(不得扣抵比率)年度調整**:兼營營業人年底最後一期要算。
- **累積留抵稅額** 要追蹤(期初 43,529)。
- 年度損益表匯出要對應「損益及稅額計算表」的科目行號(帳載欄),附:折舊明細、研發明細、非營業損益。
- 「帳載 → 稅務調整」那一欄留給報稅的人(現為田家易),系統只產乾淨的**帳載**數字 + 附表。
