# 桂圓帳房 — 儀表板怎麼看

給第一次看這套數字的人。搭配 [使用手冊.md](使用手冊.md)(怎麼操作)與 [系統文件.md](系統文件.md)(技術細節)。

> 本文所有數字為**示範假資料**,只用來說明「這個欄位在講什麼」。

---

## 這張儀表板的定位

一頁回答三個問題:

1. **現在做得如何?** —— 營收、毛利、訂單量
2. **有沒有什麼要處理?** —— 頂端「需要注意」
3. **生意的結構長怎樣?** —— 靠哪個通路、哪支產品、哪些客人

用法:每天花 2–3 分鐘掃一遍頂端警示 + 六個 KPI;每週或每月進「報表」深看。

**右上角兩個切換**
- **產季**:一個產季 = 當年 4 月初到隔年 3 月底(從開花養果算到這批桂圓乾賣完),以起始年命名。切「2024 / 2025」是比較兩批貨的成績;切「全部」看累計。
- **結算日**:算「逾期幾天 / 還剩幾天到期」的基準。平常用「最新訂單日」;想用真正的今天檢視就切「今天」。

## 一、需要注意(橘色警示區)

這區只在**有事**時才出現對應標籤,是每天第一個看的地方。每個都可點進去處理。

| 警示 | 意思 | 該做的事 |
|---|---|---|
| **貨款逾期未收 N 筆** | 出貨超過 30 天還沒收到錢 | 逐筆聯絡催款,收到後標記「已收款」 |
| **超過 3 天還沒出貨 N 筆** | 訂單成立好幾天還卡著 | 盡快打包出貨,填物流單號 |
| **破損 / 遺失待處理 N 件** | 宅配出事,還沒決定怎麼賠 | 到「物流異常」頁決定重寄 / 退款 / 折讓 |
| **批 X 約 N 天到期** | 某批桂圓快過保存期限 | 優先推這批(促銷 / 通知團購主),或轉加工 |
| **折扣佔比 X%** | 少收的錢佔比偏高(門檻 3%) | 檢視是不是折太兇、定價該不該調 |
| **待確認資料 N 筆** | 有資料沒填完整(如新客戶未分級) | 到「待確認」頁補完 |

**投影片重點:** 系統會主動把「今天該處理的事」推到你面前,不用自己去翻。

## 二、六個 KPI

以下用 **2025 產季**示範資料舉例(數字為假)。

### 1. 本產季營收 — 例:NT$ 276,000
- **問題:** 這批貨賣了多少錢?
- **算法:** 該產季所有「銷售」訂單的應收合計加總(不含贈送 / 樣品)。
- **判讀:** 和上一產季比(切「2024」對照,例:242,000 → 276,000,+14%)。單看一個數字沒意義,要看趨勢。

### 2. 毛利率 — 例:71%(毛利 NT$ 195,000)
- **問題:** 賣得多,有沒有賺?
- **算法:** (營收 − 進貨/製造成本) ÷ 營收。成本來自「批次」的單位成本。
- **判讀:** 營收成長但毛利率下滑 = 要嘛成本漲、要嘛折太多、要嘛低毛利的品項/通路佔比變高。**這是最容易被漂亮營收蓋過去的風險。**

### 3. 訂單數 / 平均每單 — 例:43 筆 / NT$ 6,420
- **問題:** 生意是「很多小單」還是「少數大單」撐的?
- **判讀:** 平均每單掉、訂單數卻沒增 → 客人買得少了。批發 / 團購佔比高會把平均每單拉高。

### 4. 本產季稅前利潤 — 例:−NT$ 240,000
- **問題:** 這一整季,把所有開銷都扣完,到底是賺還是賠?
- **算法:** 毛利 − 通路抽成 ± 運費賺賠 − 整個產季(4 月初~隔年 3 月底,含 4–8 月開花養果的淡季)的營運費用。
- **判讀:** 這是「老闆視角」的數字。毛利率很漂亮,不代表有賺 —— 淡季沒收入還是要付人事 / 場地。
  負值不一定是壞事(可能還在投入期),但要知道差多少、什麼時候能翻正。點右上「看每月完整損益」進財務健康頁逐月看。

### 5. 還沒收到的貨款 — 例:NT$ 145,000(21 筆)
- **問題:** 有多少錢還在外面?
- **判讀:** 對照營收看比例。金額大 + 筆數多 = 現金卡住,要積極追。搭配下方「應收帳齡」看是哪些拖最久。

### 6. 送出去的貨(成本)— 例:NT$ 4,400
- **問題:** 公關 / 送禮 / 樣品送掉多少「成本」?
- **算法:** 非銷售訂單的品項成本加總(這些訂單營收是 0,但貨是真的送出去)。
- **判讀:** 佔營收的比例(例 1.6%)。送人做行銷沒問題,但要知道花了多少、值不值得。

**投影片重點:** 不只看「賣多少」(營收),更要看「賺多少」(毛利)、「扣完所有開銷還剩多少」(稅前利潤)、「收到沒」(應收)。

## 二之二、KPI 下方兩張卡

### 本產季損益(濃縮版)
- 一條龍看到底:營收 → −銷貨成本 → **毛利** → −通路抽成 → ±運費賺賠 → −營運費用(整季,含淡季)→ **稅前利潤**。
- 和儀表板同步用「產季」篩選;點右上「看每月完整損益 →」進財務健康頁,可逐月拆解、維護營運費用。
- **判讀:** 中間「毛利」那行通常是正的、還不錯;真正要盯的是最後一行有沒有轉正、離轉正差多少。

### 產季目標 & 進度
- 需先到「分析 → 產季目標」設定該季的營收目標。
- 顯示:目標營收 / 實際 / **達成率**(進度條)/ 已出貨月數 / **依目前速度預估季末** / **損益兩平需營收**。
- **依速度預估季末** = 實際營收 ÷(已出貨旺季月數 ÷ 7)。旺季抓 9 月~隔年 3 月共 7 個月。用來提早知道「照這個速度,季末大概落在哪」。
- **損益兩平線** = 整季固定成本 ÷ 毛利率。實際營收越過這條線,這一季才開始真的賺錢。

## 三、趨勢與結構圖

### 月營收 / 毛利趨勢(雙線)
- 兩條線一起看:營收往上、毛利跟著往上才健康;營收漲、毛利平 = 有隱憂。
- 產季內的高峰通常在 10–11 月(送禮季前)。
- 滑鼠移過去,提示框會顯示該月營收、毛利、**毛利率**。

### 毛利率趨勢(小圖,0~100%)
- 只看「每 100 元營收留下多少毛利」的走勢,把金額大小的干擾拿掉。
- **判讀:** 線往下 = 成本漲、折扣變多、或低毛利品項/通路佔比升高。就算營收在成長,這條線往下就要查原因。

### 累積稅前利潤趨勢
- 逐月把「當月稅前利潤」加上去的一條線(不是每月單獨看,是累加)。
- 切「全部」= 從第一個月一路累計到現在(跨產季);切某一產季 = 只在那 12 個月內累計。
- **判讀:** 線在 **0 以下** = 到當月為止,前期投入(開花養果、焙製、淡月固定成本)還沒被後面的銷售獲利補回來;
  線 **爬回 0 以上** = 這段期間整體轉正、開始真的賺。看「最低點多深」「多久才回正」,就知道這門生意的資金壓力有多大。
- 淡季(4–8 月)只出不進,線會一路往下探;旺季(9 月~隔年 2 月)開始才會往上拉。

### 各銷售管道:營收 vs 毛利
- 每個通路的營收、毛利、毛利率並排。
- **重點在找「有量沒利」的通路** —— 營收排前面但毛利率明顯偏低,通常是抽成 + 運費補貼吃掉利潤(例:LINE 社群、電商平台)。
- 決策:這種通路要嘛提高客單門檻,要嘛把客人導去毛利高的管道(官網 / 自售)。

### 還沒收到的貨款(依欠多久)
- 分 **0–15 天 / 16–30 天 / 31 天以上** 三段金額。
- 「31 天以上」那段標紅,就是要打電話的名單。健康的生意這段應該很小。

### 各批賣出進度 & 到期
- 每批的賣出比例 + 還剩幾天到期。
- **看「快到期又還沒賣完」的批** —— 那是會變呆料的錢。決策:優先促銷、通知團購主、或轉做加工品。

### 物流異常(依物流商)
- 各物流商的出貨數、**異常率**、損失金額。
- 某一家異常率明顯高(例 5% 以上)→ 檢討包材、或改綁其他物流商。

### 品項銷售結構
- 每支產品的營收佔比。
- 看**哪一兩支養活這一季**(集中風險),以及**哪支是滯銷**(該不該停產或改包裝)。

### 新客人 vs 回頭客
- 回頭客營收佔比 + 回購率 + 久未回購人數。
- **回頭客佔比高 = 生意穩**;如果營收成長全靠新客、回頭客在流失,是警訊(拉新成本高、留不住人)。

### 本產季 Top 客戶
- 貢獻最高的幾位 + 分級。
- 看**營收集中度** —— 前 3 名佔一半以上,表示對大客戶依賴重,要分散。

## 四、六個報表分頁(深入分析)

儀表板是「每天掃」,報表是「每週 / 每月深看」。每頁右上可匯出 Excel。

| 分頁 | 回答的問題 | 典型行動 |
|---|---|---|
| **獲利分析** | 哪個商品 / 通路真的賺錢?實際成交價離定價多遠? | 停掉賠錢品項、調定價、收緊折扣 |
| **客戶分析(RFM)** | 誰是主力?誰久沒回來了? | 針對「久未回購」做回訪、針對主力做維繫 |
| **物流與運費** | 運費整體貼多少?哪家物流商該換? | 調運費政策、換物流商 |
| **收款帳齡** | 錢卡在哪、卡多久? | 逐筆追款、對大客戶談帳期 |
| **批次與效期** | 每批還剩多少貨、值多少錢、多久到期? | 排促銷順序、估何時要再焙下一批 |
| **跨產季比較** | 今年這批比去年那批好嗎?哪個月差? | 找出衰退的月份 / 品類,調整下一產季策略 |

## 五、給簡報的敘事線(建議順序)

1. **開場 — 這是什麼**
   一頁掌握桂圓生意的營運;資料留在自己電腦,不上雲。

2. **現況 — 賣得如何、賺得如何**
   本產季營收 vs 上一產季 → 毛利率 → 平均每單。
   關鍵訊息:營收會說謊,毛利不會。

3. **風險 — 系統主動提醒**
   「需要注意」六種警示 → 應收帳齡 → 批次效期 → 物流異常。
   關鍵訊息:該處理的事會自己浮出來,不靠人記。

4. **結構 — 生意靠什麼撐**
   通路營收 vs 毛利(有量沒利)→ 品項集中度 → 新客 vs 回頭客 → Top 客戶集中度。
   關鍵訊息:知道生意的重心和脆弱點在哪。

5. **收尾 — 這套數字幫你做的三個決定**
   - 定價與折扣要不要調(獲利分析)
   - 哪個通路 / 品項要加碼或收掉(通路與品項結構)
   - 現金與呆料的風險在哪(帳齡、批次效期)

## 六、常見誤解

- **「營收成長就是好」** —— 不一定。要同時看毛利率有沒有跟上、應收有沒有暴增。
- **「產季 = 西元年」** —— 不是。產季是「那批貨的完整週期」:當年 4 月開花 → 隔年 3 月賣完,以起始年命名。
- **「結算日的日期怪怪的」** —— 示範資料用「最新訂單日」當今天,所以看起來像過去。真的即時輸入訂單後就會貼近現在。
- **「毛利率好像偏高」** —— 因為示範資料的批次成本是抓的估值;換成真實成本後會回到合理區間。
