# 桂圓帳房 — 使用手冊

這份是**照畫面分區的查閱型手冊**——想知道某個畫面怎麼操作,照目錄找那一節看就好,
不是照做生意的順序排的。**第一次上手、想照順序走一遍完整流程**,請看
[營運流程SOP.md](營運流程SOP.md);同事想深入了解每個畫面怎麼記帳、對應什麼會計科目,
看 [功能手冊.md](功能手冊.md);技術細節見 [系統文件.md](系統文件.md)。

---

## 一、開始使用

1. 打開 `app` 資料夾,**雙擊 `啟動.bat`**。
2. 第一次會跑一兩分鐘裝東西,之後很快。
3. 出現黑色視窗、瀏覽器自動打開 **http://127.0.0.1:8000** 就成功了。
4. **用的時候黑視窗不要關**,關了網站就停了。用完直接關視窗即可。

> 目前畫面上的數字是「示範假資料」,可以放心點來點去練習。等要正式用,再把真資料建進去(或請人協助匯入)。

![儀表板](screenshots/manual/dashboard.png)

### 在 iPad / 手機上用(同一個 Wi-Fi)

App 跑在電腦上,iPad 只是「遠端的螢幕」——**電腦要開著、`啟動.bat` 要在跑**。

1. 電腦、iPad 連**同一個 Wi-Fi**。
2. 看 `啟動.bat` 黑視窗裡印出的 `http://192.168.x.x:8000`(那台電腦的區網位址)。
3. iPad 用 Safari 打那個網址。
4. Safari 分享鈕 →「**加入主畫面**」→ 桌面就有一顆「桂圓帳房」圖示,點開全螢幕,像 App 一樣。

> 第一次連,Windows 可能跳出防火牆詢問,選「允許」。
> 離開這個 Wi-Fi 就連不到;資料一直都只在那台電腦上。

## 二、畫面導覽(左側選單)

選單分四區,點區名可以收合展開(**你自己收合/展開的狀態,這台電腦、這個瀏覽器會記住**,
換頁不會彈回去):

| 區 | 選單 | 用途 |
|---|---|---|
| | **儀表板** | 一頁看營運全貌;最上面「需要注意」是今天該處理的事 |
| | **＋ 記一筆(九宮格)** | 要記哪一種交易的入口頁,九張卡片點進去就是原本的畫面(詳見第四節) |
| 每天做的 | **訂單** | 所有訂單清單;點「＋ 新增訂單」開單;點單號看 / 改一張訂單 |
| 每天做的 | **付小農貨款** | 付錢給小農時登記一筆;也看得到目前還欠小農多少(第五節之 8) |
| 每天做的 | **營運費用** | 逐月登記房租、人事、驗證費等固定支出 |
| 出貨 / 退貨 | **出貨作業** | 揀貨單、出貨標籤 / 送貨單、食品標示,都可列印;右上「物流異常處理」處理破損 / 遺失 / 退貨 |
| 出貨 / 退貨 | **退款 / 退回小農** | 只退錢不退貨、或貨退給小農的紀錄;在訂單頁登記(第五節之 7)。退貨又退款直接刪訂單 |
| 看數字 | **財務健康** | 每月從營收算到稅前利潤 + 累積稅前 + 毛利率趨勢(要先填每月營運費用) |
| 看數字 | **獲利報表** | 三個分頁:獲利分析 / 收款帳齡 / 跨產季比較,可匯出 Excel |
| 看數字 | **定價試算** | 抓成本、算單位成本、對照售價的估算工具;**純參考,不會動到帳上任何數字** |
| 看數字 | **全鏈路毛利** | 把付給小農的成本往前拆解,估算供應端大概賺多少(第十五節) |
| 看數字 | **總帳** | 系統依你填的業務資料自動組出的傳票,主要給同事核對帳務用;刪除 / 編輯傳票也在這裡(見第四節) |
| 看數字 | **正式報表** | 同事做帳 / 報稅用的試算表 / 資產負債表 / 綜合損益表(第十三節) |
| 看數字 | **銀行帳戶明細** | 現金 / 各銀行帳戶各自的進出流水 + 累計餘額(見第四節) |
| 設定一次的 | **客戶資料庫** | 客戶名單、明細、新增、編輯、合併重複 |
| 設定一次的 | **商品目錄** | 你賣的每個品項規格、定價、單位成本(= 跟小農買一份要付多少) |
| 設定一次的 | **銷售管道** | 官網 / 市集 / 批發 / LINE… |
| 設定一次的 | **固定資產** | 焙灶 / 剝殼機 / 搖蜜機 / 冷藏 / 貨車… 建卡後系統每月自動提折舊,算進財務健康,也會記進總帳 |
| 設定一次的 | **銀行帳戶** | 各付款帳戶的固定代碼,可以改名 / 併入重複的帳戶(第九節) |
| 說明文件 | **下載手冊** | 下載這份手冊、功能手冊、SOP 的最新版本,單一 .html 檔,離線也能看(第十九節) |

- **待確認**(系統提醒有資料沒填完整)、**產季目標**(設定整季營收目標)沒放在選單裡:
  待確認從儀表板「需要注意」的紅字進;產季目標從儀表板「產季目標 & 進度」卡點「設定目標」進。
- 右上角(儀表板、報表頁)可切 **產季**(可複選,預設最新一季)。
- 儀表板、財務健康、獲利報表這幾頁,**產季**旁邊還有「依產季 / 依西曆年」切換鈕——
  平常用產季看就好(配合龍眼生長週期);想用一般日曆年(1~12 月)看的時候切過去,
  數字會重新用西曆年算一次。這個切換**跟第十三節「正式報表」固定用西曆年不一樣**:
  正式報表不能選,這裡才是可以自己選的。

## 三、一個核心觀念:分開建檔

這套系統把資料分成兩種,**觀念對了,操作就順了**。

### 主檔 —— 建一次,之後一直用
像通訊錄和型錄。內容不常變,先建好放著。

| 主檔 | 就是 | 建的時機 |
|---|---|---|
| **銷售管道** | 官網 / 市集 / 批發 / LINE… | 一開始建好,很少再動 |
| **商品目錄** | 每個品項規格(桂圓乾 300g、龍眼肉 600g…)+ 各分級定價 | 有新品或改價時 |
| **客戶** | 每一個買過的人 / 店 / 單位,含電話、地址、分級 | 第一次跟這個客人往來時 |

### 交易 —— 每次發生就記一筆
就是 **訂單(+ 訂單明細)**。每賣一次記一張。

### 關鍵:訂單不是「重打一次資料」,是「挑」

開一張訂單時,你**不會**再輸入客戶的電話地址、也不會重打商品名稱和售價 ——
你只是從既有的客戶清單「挑一個人」、從商品目錄「挑幾樣東西」,填數量,系統自動帶價。

```
         ┌─ 客戶(挑一個)
訂單 ────┼─ 銷售管道(挑一個)
         └─ 訂單明細 ── 商品(挑) × 數量 × 單價
```

### 為什麼要這樣分

1. **不用重複輸入** —— 老客戶下第 10 張單,不用再打一次他的資料。
2. **資料一致** —— 客戶電話改一次,所有相關訂單都跟著對;不會這張寫對、那張寫錯。
3. **報表才算得出來** —— 因為每張訂單都連到「同一個客戶編號」「同一個商品編號」,系統才能把「這個客人買過幾次」「這支產品賣多少」串起來。名字打得不一樣,系統就當成不同人 / 不同東西,報表就亂了。

### 建立順序(第一次導入時)

**先** 銷售管道 → **再** 商品目錄(順便設定價、單位成本)→ **再** 客戶 → **最後才** 開訂單。
(平常運作時,只有「客戶」會邊做邊補;商品和管道很少動。)

### 一個比喻

- 商品目錄 = 菜單
- 客戶資料庫 = 常客名冊
- 訂單 = 一張出貨單:寫「誰、點了菜單上的哪幾樣、幾份」,不會把整份菜單和客人的身家再抄一遍。

### 郡碩是「接單才跟小農買」(2026-10 起的做法)

郡碩**沒有存貨**:有客人下單,才跟小農買貨、轉手賣給客人。所以系統裡**沒有「進貨」「庫存」**
這兩件事,改成這樣記:

- **開一張訂單** → 系統同時記兩件事:客人欠我們多少(含稅),以及我們欠小農多少
  (= 商品目錄裡的「單位成本」× 數量)。
- **客人付款** → 在訂單上標記已收款。
- **付錢給小農** → 到「付小農貨款」登記一筆。小農只有一個,不用分人。
- **售價都是含稅價**,每張訂單的「銷項稅額」由你自己填,系統不幫你算。

商品的「單位成本」會在**開單那一刻**抄一份存進訂單。之後換季改了商品目錄的成本,
舊訂單照當初的成本算,不會跟著變。

## 四、記一筆(九宮格)—— 要記帳,先看這頁

側邊選單「＋ 記一筆(九宮格)」是所有記帳動作的統一入口,九張卡片對應九種交易,
點進去就是原本的畫面填,系統會自動組出分錄記進「總帳」(下一節說明)。

![記一筆九宮格](screenshots/manual/entry.png)

**你每天真正會用到的只有前 3 張**(對應第二節「每天做的」那三個選單):

| 卡片 | 就是 | 多常用 |
|---|---|---|
| 銷售 / 出貨 | 訂單 | 每天 |
| 付小農貨款 | 付錢給小農時登記 | 常常 |
| 營運支出 | 營運費用(包材、房租、人事…都在這裡記) | 每月 |
| 設備相關 | 固定資產 | 買設備才會用到 |
| 其他收益 | 利息收入、政府補助等不是賣東西賺來的錢 | 很少 |
| 其他費用 | 其實併進「營運支出」的類別選單裡,不是另一個畫面 | — |
| 資本異動 | 增資、盈餘轉列公積 | 幾乎不會用到,同事在管 |
| 帳務調整 | 其他類都套不上時,手動記一筆(要懂借貸科目)| 幾乎不會用到,同事在管 |

「其他收益」「資本異動」「帳務調整」這幾張是給比較特殊的情況用的,平常
用不到也沒關係;真的要用,填法都很直覺(日期、金額、備註幾個欄位),存檔就自動記好。

### 總帳是什麼

**總帳**(選單「看數字 → 總帳」)是系統依你上面填的每一筆業務資料,自動組出來的
會計分錄明細——你不用懂「借方 / 貸方」是什麼,這頁主要是給比較懂記帳的同事核對
帳務對不對用的。你只要記得:**這裡的內容不能直接改,要改回去改原本那筆訂單 / 費用,
總帳會自動跟著更新**。

- 傳票號碼一律是 `GL` + 日期 + 當天流水號,例如 `GL20260921001`。
- 預設依傳票號碼由小到大排(也就是由舊到新)。科目代碼跟科目名稱分兩欄顯示。
- **要刪除或編輯傳票**:用上方「刪除或編輯傳票」,**先選日期、再選那一天的傳票號碼**,按「篩選」。
  篩到那一張之後才會出現「刪除整張傳票」跟「編輯」兩個按鈕。一次只能處理一整張,不能批次刪。
  - 刪除會連同產生這張傳票的原始資料(那張訂單、那筆費用…)一起刪掉;訂單的傳票會把整張訂單刪掉。
  - 編輯會帶你回到原始資料那頁修改,存檔後傳票自動更新。
  - 設備取得 / 折舊要到「固定資產」處理,年度結轉要到「正式報表」撤銷,這裡不能直接刪。

![總帳:先篩出指定日期的傳票,才出現刪除 / 編輯按鈕](screenshots/manual/ledger.png)

## 五、每天最常做的事

### 1. 開一張新訂單

**訂單** 選單點進去先看到清單,右上「＋ 新增訂單」開新單。

![訂單清單](screenshots/manual/orders-list.png)

![新增訂單](screenshots/manual/order-new.png)

1. **訂單日**:預設今天,需要可改。
2. **客戶**:在框裡打名字或電話,下面會跳出清單。每筆會顯示「分級 · 電話 · 最近購買 · 幾筆訂單」,**認清楚是哪一位再點**。
   - 選好後下方會出現一張小卡:電話、地址、最近 3 筆訂單、累計消費 —— 再確認一次沒選錯人。
   - **名單裡找不到** → 點「找不到?先去新增客戶 →」,把客戶建好會自動跳回來。
3. **銷售管道**:這張單從哪來(官網 / 市集 / 批發…)。
4. **訂單種類**:一般賣就是「銷售」;送人選「贈送-公關」;補寄選「理賠重寄」等。
5. **訂單明細**:
   - 每列選品項、填數量。
   - **單價留空會自動帶入該客戶分級的定價**;要特價就自己打。
   - 不夠填 → 點「＋ 加一列」;多的 → 點「刪」。
   - 搭贈的東西可以加一列、勾為「贈品」(不算錢)。
6. **物流**:出貨方式、運費(花多少錢)、運費由誰負擔。**店家吸收**(預設):運費是家易自己的開銷,不跟客人收,不影響應收合計。**客戶付**:客人要付的錢本來就含運費(錢收齊才出貨),應收合計會自動多算這筆運費。
7. **收款**:付款方式、收款狀態(還沒收就「待收款」)。
8. **發票**:有開發票就勾「已開發票」——**勾了之後發票號碼欄位會變成必填**,沒填不給存檔;沒開發票就不用勾,發票號碼留空即可。
9. **銷項稅額**:售價都是含稅價,這張訂單含了多少稅**請自己填**,系統不會幫你算。
   填負數、或比商品金額還大會被擋下來。總帳會把客人付的錢拆成「銷貨收入」跟「銷項稅額」兩部分。
10. **存檔並建立訂單** → 會跳到這張訂單的明細頁。

![訂單明細](screenshots/manual/order-detail.png)

### 2. 一次匯入很多筆訂單(選用)

如果訂單是從 Google 表單收單、或是客人用 Excel 給你一批名單,不用一筆一筆手動開——
訂單清單頁右上角「匯入」,選「銷售管道」,上傳 `.csv` 或 `.xlsx` 檔案:

![匯入訂單,選銷售管道、上傳檔案](screenshots/manual/order-import.png)

檔案表頭要用固定格式(時間戳記 / 客戶姓名 / 客戶電話 / 收件地址 / 付款方式 / 備註,
其餘每欄對應一個商品品名或 SKU,填數量)。**不確定欄位怎麼打,直接點畫面上「下載範本
(.csv)」**——系統會依照現在「在售」的商品清單,自動產生欄位名稱都排好的範本檔,打開
照第一列範例的格式往下填就對了(範例那一列記得刪掉再上傳)。上傳之後系統**先給你看
預覽**,不會直接建單:

![匯入預覽,顯示可匯入/待確認/有問題/重複的筆數](screenshots/manual/order-import-preview.png)

- **可匯入**:客戶、商品都比對成功,確認就會直接建單。
- **待確認**:電話找不到對應的既有客戶,系統會問你要「建立新客戶」還是指到既有客戶。
- **有問題**:格式不對、品項對不到商品的列,不會被匯入,回原始檔案修正後可以重新上傳。
- **之前已經匯入過**:同一份檔案重複上傳也沒關係,已經匯入過的列會自動略過,不會變成
  兩筆重複訂單。

看一輪沒問題,按「確認匯入」才會真的建立訂單。

> **匯入的訂單,銷項稅額是 0**,匯完記得一張張進訂單頁補填。

### 3. 收到貨款了

打開那張訂單(訂單清單點單號,或儀表板「貨款逾期未收」點進去)。
「收款」卡裡先填**實收金額**(實際收到多少就填多少,不一定等於訂單金額 —— 部分收款就填實際收到的數)、
收款日,再按右上角 **「標記已收款」**。**本產季營收算的是這個實收金額,不是訂單開的金額** ——
沒標記收款,這張單再大都不會算進營收 / 毛利裡。系統也會同時在總帳補一筆收款分錄,不用你管。

### 4. 出貨了

打開訂單,「出貨」卡裡先選**出貨方式**(宅配 / 超商店到店 / 自行配送…),出貨日沒填會
自動帶今天,再按右上角 **「標記已出貨」**(沒選出貨方式會提醒你,不會讓你直接按過去)。
要記物流單號 → 在「出貨」區填 **物流單號**、必要時改物流商、出貨狀態,按下方「儲存」。

### 5. 改一張已建立的訂單

打開訂單明細頁:
- **品項**:直接改品項 / 數量 / 單價,加減列,按「儲存」→ 金額自動重算。原本就在單上的商品,
  成本維持開單當時的數字;新加進來的商品才用商品目錄現在的成本。
- **改客戶**:上方「客戶」框重新搜尋、選一位,按「儲存」。
- **複製訂單**:右上「複製訂單」→ 同客戶、同品項、同稅額開一張新單(日期填今天),適合回頭客重複下同樣的東西。
  新單算新的一筆交易,成本用商品目錄現在的數字。
- **刪除訂單**:右上「刪除訂單」,會問一次確認。刪掉後**沒辦法復原**,連同這張單的品項、退款紀錄、
  總帳傳票都會一起刪掉,欠小農的錢也跟著扣回去。建錯單,或是**客人退貨又退款**,都是用這個。

### 6. 包裹破損 / 遺失

**物流異常** 頁:
- 找到那筆,選「處理方式」(重寄 / 退款 / 換貨 / 折讓),填說明。
- 要重寄 → 勾 **「一併建立理賠重寄單」**,系統會複製原訂單品項、開一張金額 0 的重寄單。
- 按「儲存」。

### 7. 客人退貨 / 退款

先分清楚是哪一種:

| 情況 | 怎麼做 | 系統怎麼記 |
|---|---|---|
| **退貨又退款**(貨退回來、錢也還給客人) | 直接按訂單右上「**刪除訂單**」 | 這張訂單跟它的傳票全部刪掉,就像沒發生過 |
| **只退款、不退貨**(貨不用退,補償客人一點錢) | 訂單頁最下方「退款 / 退回小農」,類型選「**退款**」,金額填退給客人多少 | 不管退多少,一律算「其他支出」(目前用 6499 其他損失) |
| **退貨但不退款**(客人退貨,錢不退) | 同上,類型選「**退回小農**」,金額填小農還給我們的成本 | 貨退給小農、小農把成本還給郡碩,欠小農的錢跟著減少 |

畫面上會顯示這張訂單的**成本合計**,如果貨全部退回小農,金額就填這個數字。
已經收過款的訂單,退款會記成真的從帳戶退錢出去;還沒收款的,會記成客人少付這筆。

![訂單明細,最下方是退款 / 退回小農](screenshots/manual/order-detail.png)

左側選單「退款 / 退回小農」可以看全部的紀錄,下方分別合計「退給客人多少」「小農退回多少」。

![退款 / 退回小農清單](screenshots/manual/returns.png)

### 8. 付錢給小農

左側選單「**付小農貨款**」。每開一張訂單,系統就會照商品成本自動記一筆「欠小農的錢」;
真的付錢給小農時,在這裡登記付款日、金額、從哪個帳戶付,欠款就會減少。

![付小農貨款,上方看得到目前還欠多少](screenshots/manual/farmer-payments.png)

- 上方「**目前還欠小農**」= 所有訂單的成本 − 已經付的 − 小農退回的。
- 小農只有一個,不用選對象。
- 登記錯了,按那一列的「刪」,總帳的傳票會一起刪掉。

### 9. 記一筆營運費用

**營運費用** 選單先看到逐月清單,右上「＋ 新增一筆」選月份、項目、填金額。

![營運費用清單](screenshots/manual/expenses-list.png)

一次性大支出(研發、設備零件)可設
「攤提月數」,系統會分月認列進財務健康的損益,但**總帳這邊記的是存檔當下現金真正付出去的
全額**——這兩個數字本來看的東西不一樣,不是算錯。

如果類別選到「研發」,畫面會提醒你:如果是設備 / 機器的零件、組裝費用,建議改到「固定資產」
登記才會正確逐年提折舊;「研發」比較適合沒有形成實體設備的費用(配方試驗、委外檢驗)。

![新增營運費用](screenshots/manual/expense-new-rnd-hint.png)

存檔前會先看一張「確認分錄」畫面,系統依你剛剛填的內容自動組好分錄草稿,科目代碼跟科目名稱分開列。
看一眼付款帳戶、稅額對不對,不確定就留預設值,按「確認存檔」才會真的存進去。
**憑證類型選了「發票」,發票號碼也是必填的。**

![營運費用確認分錄](screenshots/manual/expense-confirm.png)

> **包材、紙箱這類開銷也在這裡記**(類別選「其他費用-包裝費」)。系統已經沒有「進貨」頁了。

## 六、客戶

### 新增

**客戶資料庫 → ＋ 新增客戶**。填名稱(必填)、電話、**分級**(零售 / 批發 / 團購主 / 機構 / 公關對象 —— 影響自動帶價)、主要管道、發票抬頭 / 統編、單據需求、預設收件地址。

![客戶資料庫](screenshots/manual/customers.png)

### 搜尋

清單上方搜尋框,可打名字、舊稱呼、電話。

### 重名怎麼辦

- 建檔時如果已有同名,系統會列出現有那幾位(含電話、最近購買、地址),請你判斷:
  - **同一人** → 按「取消」,回去選現有那位。
  - **不同人** → 名稱加個能區分的字(電話末碼、地區、來源,如 `陳美玲(0912…321)`),勾「確認這是不同的人,仍要新增」。
- 系統靠「客戶編號」認人,名字一樣也是不同資料、各自的訂單歷史。

### 合併重複客戶

不小心建重了 → 打開其中一位的明細頁 → 右上「**合併到其他客戶**」→ 搜尋要**保留**的那位 → 確認。
來源客戶的所有訂單、地址、舊稱呼都會搬過去,來源被刪除。**無法復原,請看清楚再按。**

### 刪除客戶

客戶編輯頁也能「刪除」,但只要這位客戶已經有訂單就會被擋下來(系統會直接說明原因)。
建錯、從沒下過單的客戶才刪得掉;已經有交易紀錄的客戶,想處理重複請用上面的「合併」。

## 七、主檔維護(商品 / 管道)

### 商品目錄
- 「＋ 新增商品」/ 每列「編輯」。
- **商品編號**:每種品項＋規格一個專屬代號(桂圓乾 300g 一個、500g 另一個)。定好**不要再改**,所有訂單靠它連回商品。
- **單位成本**:跟小農買這個品項一份要付多少(例如一包 300g 桂圓乾)。開訂單時系統拿它算「欠小農多少」,
  「毛利」「稅前利潤」也是拿營收扣這個數字,填得準不準直接決定帳準不準。開單那一刻會抄一份存進訂單,
  之後改這裡只影響新開的訂單。
- 表單最下面「**定價**」:填零售 / 批發 / 團購 / 機構 / 內部各自的價,新增訂單就會自動帶。
- 商品編輯頁可以「刪除」,但如果已經有訂單用過它,系統會擋下來並具體說明卡在哪(例如「有 5 張訂單用過這個商品」)。

![商品目錄](screenshots/manual/products.png)

### 銷售管道
- 「＋ 新增管道」:代碼、名稱、分類、帳期天數。
- 同樣可以「刪除」,若已經被訂單、客戶(設為主要管道)或定價用過會被擋下並說明原因。

![銷售管道](screenshots/manual/channels.png)

## 八、固定資產

**固定資產** 頁登記焙灶、剝殼機、搖蜜機、冷藏、貨車這類不是一次性費用、要逐年提折舊的設備。

![固定資產](screenshots/manual/assets.png)

- 「＋ 新增一台」填名稱、類別、取得日、成本、政府補助款(有才填)。
- **耐用年數最少 10 年**,預設就是 10 年(房屋建築 30 年);填低於 10 年會被擋下來。
- **殘值一律是 0**,不用填,畫面上也不能改。
- **付款帳戶用選的**:現金,或已經建立的銀行帳戶。清單裡沒有的新帳戶,選「其他帳戶(手動輸入)」再打名稱。
- 存檔後系統會自動記一筆「設備取得」分錄,以後每個月你打開這頁,系統會順便把還沒記過的
  折舊月份補齊,不用手動一筆一筆記。
- 處分(賣掉 / 報廢)才填「處分日」,填了之後就不會再繼續提折舊。

![新增固定資產](screenshots/manual/asset-new.png)

## 九、銀行帳戶(主檔)

訂單 / 營運費用 / 付小農貨款這些畫面的「付款帳戶」欄位,第一次打過的銀行名稱就會自動出現在
這裡,系統自動配一個固定代碼(現金不用列,留白就是現金)——**不用先來這裡「新增」才能用**,
照常在那些畫面打名字存檔就好。

![銀行帳戶清單,可以改名或併入別的帳戶](screenshots/manual/bank-accounts.png)

這頁能做的兩件事:

- **改名**:打錯字、或銀行名稱異動,直接改,連已經記過的舊傳票也會一起更新,不會拆成兩筆。
- **併入**:發現同一家銀行不小心被打成兩個不同名字(例如「合庫」「合作金庫」各記了幾筆),
  選「併入」把其中一個併進另一個,舊傳票會自動改成合併後的代碼,原本那個帳戶會被刪掉
  (**這個動作沒辦法復原**,按下去前系統會再跟你確認一次)。

代碼一旦指派就不會再變,所以這頁**沒有「刪除」**,不想用的帳戶放著不管就好,不影響任何東西。

## 十一、看儀表板

整理過後,儀表板只留「一眼要看的」:

- **需要注意**(橘色區):今天該處理的事,每個標籤可點進去處理(逾期未收 / 待出貨超時 / 破損遺失 / 待確認資料)。
- **4 個 KPI**:本產季營收(**已經實收的錢,扣掉銷項稅額**,還沒收到的訂單不算)、**本產季稅前利潤**、毛利率、還沒收到的貨款。
- **本產季至今損益簡表**:營收(不含稅)→ −退款 → −銷貨成本 → 毛利 → −運費 → −營運費用 → **稅前利潤**,一次看完,右上連到財務健康看每月明細。進行中的產季,營運費用只算「已經過去的月份」,不會預先把還沒發生的費用也算進去,避免季初看起來嚇人的赤字。
- **產季目標 & 進度**:目標營收 / 實際 / 達成率 / 依速度預估季末 / 損益兩平需營收(先點卡上「設定目標」到產季目標頁設定)。
- **月營收 / 毛利趨勢**:儀表板唯一一張圖,滑過看各月金額與毛利率。
- 右上角可複選 **產季**(那個產季有訂單、或你登錄過那季的營運費用,就會出現在下拉),預設選最新一季。「逾期幾天」一律用**今天**的日期算,不用另外切。

> 更深入的看法搬到別頁:累積稅前利潤、毛利率趨勢 → 財務健康;各通路 / 品項 / 新客回頭 / Top 客戶 → 報表「獲利分析」。

每個分頁右上角有 **「匯出這頁 CSV ↓」**,會帶入目前選的產季,用 Excel 打開中文正常。
訂單、客戶清單頁也各有匯出鈕。

![獲利分析](screenshots/manual/reports-profit.png)

### 財務健康(月損益)

報表看的是「毛利」;**財務健康** 這頁再往下算到 **稅前利潤**。

![財務健康](screenshots/manual/finance.png)

- 上方選月份。表格由上到下:營收 → −銷貨成本 → 毛利 → −運費 → −各項營運費用 → **= 稅前利潤**(綠色代表有賺、紅色代表虧)。
- **營收、成本、毛利、運費** 由系統的實際訂單自動算,營收算的是**已收到的實收金額扣掉銷項稅額**。
  退款從營收扣掉;小農退回的成本從銷貨成本扣掉。
- **營運費用要你逐月填** —— 點右上「維護營運費用」→「＋ 新增一筆」。每筆可標:
  - **項目**:直接人工 / 驗證費 / 研發 / 人事 / 場地・倉儲 / 行銷 / 金流手續費 / 設備維護 / 培訓 / 其他,以及一批更細的「其他費用-XX」子項(什項購置 / 勞務費 / 設計費 / 手續費 / 交通費 / 包裝費 / 檢驗費 / 印刷費 / 規費 / 燃料費),還有文具用品 / 交際費 / 捐贈 / 伙食費 / 職工福利 / 佣金支出 / 進出口費用 / 產品保固費用 / 利息費用。
    （原本有「田間管理」這個項目,2026-10-01 拿掉了——郡碩是跟小農 / 合作社採購鮮果,
    不是自己種,田間管理的成本已經包含在採購價裡,不用另外記一筆費用)
  - **攤提月數**:一次性大支出(研發、設備)填 N,系統分 N 個月認列。金額欄填實際花的錢,合計不變。
- **損益兩平點**:固定成本 ÷ 毛利率 = 每月營收要做到多少才不虧;和本月實際營收比對。
- **月稅前利潤趨勢**:一眼看出哪幾個月在賺、哪幾個月被固定支出吃掉。**淡月(4–8 月是開花養果期、幾乎沒收入)照樣有人事房租,所以是紅的** —— 這正是要盯的地方,營運費用淡月也要記。
- **各產季合計**:已經結束的產季,拿整季收入減掉整年 12 個月的開銷,回答「這批桂圓到底賺不賺」;還在進行中的產季,只減掉「已經過去的月份」的開銷,不會預先算進還沒發生的支出。

> 沒填營運費用的月份,稅前利潤會等於毛利(偏高、不準)。要準,每個月都要把開銷填進去。

### 銀行帳戶明細

**銀行帳戶明細**(選單「看數字」)是依帳戶(現金 / 各家銀行)整理出來的進出流水,
逐筆算累計餘額。上方分開顯示這個帳戶的科目代碼跟科目名稱。帳戶名單是你之前在訂單 / 費用 / 付小農貨款等地方填過的「付款帳戶」名稱,
不用另外維護。**同一個帳戶,每次都要打一樣的名稱**(例如都打「郵局」,不要這次打
「郵局」下次打「中華郵政」),不然系統會把它們當成兩個不同帳戶,餘額就會兜不起來——
如果真的不小心打成兩個名字了,不用擔心,去「銀行帳戶」頁(見第九節)用「併入」
合併回同一個就好,不用重打舊傳票。

![銀行帳戶明細](screenshots/manual/cash.png)

### 產季目標

側邊欄「分析 → 產季目標」:每個產季填一個整季營收目標,存檔後儀表板的「產季目標 & 進度」卡就會算達成率、
依速度預估季末、損益兩平需營收。**還沒開賣、只有前期投入費用的產季**(例如 4–8 月剛登錄完營運費用、還沒下第一筆訂單)
也會出現在這頁和產季下拉裡,方便你提早設目標、看前期燒了多少。

## 十三、正式報表

這是給同事做帳 / 報稅用的**正式會計報表**,跟前面「看報表」「財務健康」那些給自己看
經營狀況的報表不是同一回事——這裡的數字直接從總帳算出來,一分一毫要對得起來;前面
那些是方便自己看生意好不好的估算版,兩邊口徑本來就不會完全一樣,不用覺得奇怪。

側邊欄「看數字 → 正式報表」,右上角選年度(**這裡固定用西曆年 1~12 月**,跟系統其他
地方「產季」4 月到隔年 3 月不是同一條時間軸——這也是刻意的,報稅本來就要用西曆年)。
三個分頁:

![試算表](screenshots/manual/statements-trial.png)

- **試算表**:**所有科目**累計到這一年底為止的借貸餘額,沒有金額的科目也會列出來、顯示 0。
  右下角有一個檢核值,正常情況下永遠是 0。上方「**下載試算表(Excel 可開)**」可以下載成檔案,
  用 Excel 直接打開,中文不會亂碼。
- **資產負債表**:資產 / 負債 / 權益,截至年底的餘額。
- **綜合損益表**:這一年(進行中的年份只算到今天)的收入 / 成本 / 費用明細,算出本期損益。

三張表都是固定欄寬,科目代碼、科目名稱、金額各一欄,視窗放大也不會被拉長。

![資產負債表](screenshots/manual/statements-bs.png)
![綜合損益表](screenshots/manual/statements-is.png)

年度結束後,按右上角「產生 OOOO 年度結轉」,系統會真的貼一筆傳票,把這一年收入/成本/
費用科目的餘額歸零、淨額轉進「累積盈虧」——這樣下一年的試算表才會正確疊加。按錯了可以
「撤銷結轉」。**這個動作同事應該比較熟悉什麼時候該按,平常不用主動去按。**

## 十五、全鏈路毛利分析

郡碩沒有自己的果園,但老闆（家易）自己有果園——郡碩是跟他買鮮果或加工品,買鮮果可能
自己加工再賣、也可能買加工品直接包裝賣。儀表板、總帳、這份手冊前面講的所有報表,**都是
公司角度**:從公司付給小農的錢開始算,不會看到供應端自己種 / 自己加工花了多少成本。

**全鏈路毛利分析**(選單「看數字」)就是另外補這一塊——把付給小農的成本**往前拆解**,
估算裡面大概多少是供應端自己的成本、供應端大概賺多少,給自己決策參考用。**不是多算
一筆錢**,金額不會因為這頁而改變,總帳跟正式報表都不會被這頁影響。

![全鏈路毛利分析,四條產品線各一張卡](screenshots/manual/chain-margin.png)

- 上半是真實數字(營收、付給小農的成本、運費、公司端毛利),系統自動算好,不用填。
- 中間「供應端生產成本估算」是你自己填的——不管這批是鮮果還是加工品,大概估一個供應端
  自己的成本就好,不用糾結細節。
- 下半自動算出「供應端估算淨利」「全鏈路毛利率」。估出來供應端倒賠(紅字)不是系統錯了,
  是提醒你:可能是估算數字偏高,或採購價真的壓得比較低。

這個估算**依產季分開存**,換一季預設會帶上一季的數字,改完記得按「儲存這一季的估算」。

## 十六、資料安全

- **每次啟動會自動備份**一份當天的資料庫到 `app\備份\` 資料夾,保留最近 30 天。
- 想還原到某天:**關掉 App** → 到 `備份\` 找到那天的檔 → 複製到 `app\` 底下、改名成 `guiyuan_ledger.db`(蓋掉現有的)→ 重新啟動。
- 建議**每隔一陣子把整個 `app` 資料夾複製到隨身碟或雲端**,電腦壞了才有得救。

## 十七、名詞小辭典

| 詞 | 意思 |
|---|---|
| **產季** | 一批桂圓的完整週期:當年 4 月初開花養果 → 隔年 3 月底賣完,以起始年命名(如 2026 產季 = 2026-04 ~ 2027-03)。銷售集中在 9 月~隔年 2 月。不是單純的西元年。 |
| **毛利** | 營收扣掉商品的單位成本後剩下的。毛利率 = 毛利 ÷ 營收。 |
| **實收金額** | 這張訂單實際收到的錢(標記已收款時填的),系統算營收 / 毛利都用這個,不是訂單開出來的金額。 |
| **運費** | 這張訂單實際花出去、付給物流商的錢。「運費由誰負擔」選**店家吸收**時只是家易自己的開銷,不影響應收合計;選**客戶付**時客人要付的錢含運費,應收合計會自動多算這筆。不管誰負擔,這筆錢對公司的淨損益都不受影響(客戶付的部分只是代收代付)。 |
| **折扣** | 賣得比「定價」低的差額(系統即時算,不影響訂單應收金額本身)。 |
| **分級** | 客戶類型(零售 / 批發 / 團購主 / 機構 / 公關對象),決定新增訂單自動帶哪個價。 |
| **待確認** | 系統發現的不完整資料(例:新客戶還沒指定分級),補完後標記處理。 |
| **理賠重寄** | 包裹出事後重新寄一份,金額算 0,不算營收。 |
| **已開發票** | 訂單 / 費用上的一個勾選(或憑證類型選「發票」)+ 發票號碼欄位,**勾了 / 選了就一定要填發票號碼**。 |
| **銷項稅額** | 售價裡含的稅。每張訂單由你自己填,系統不算;總帳會把它跟銷貨收入分開記。 |
| **欠小農的錢(應付帳款)** | 每開一張訂單,系統照商品成本自動記的「要付給小農的錢」;付款時到「付小農貨款」登記。 |
| **退款 / 退回小農** | 只退錢不退貨 = 退款(算其他支出);貨退給小農、錢不退客人 = 退回小農(小農退成本)。退貨又退款直接刪訂單。 |
| **傳票號碼** | `GL` + 日期 + 當天流水號,例如 `GL20260921001`。 |
| **總帳 / 分錄 / 傳票** | 系統依你填的業務資料自動組出的會計記錄,平常不用管,看第四節。想深入了解看 [功能手冊.md](功能手冊.md)。 |
| **付款帳戶** | 費用 / 付小農貨款 / 其他收益等畫面填的「用哪個帳戶收付款」,留空 = 現金;同一個帳戶每次要打一樣的名稱。固定資產是用選的。 |

## 十八、常見問題

**Q:我改了東西,畫面沒變?**
A:如果只是新增 / 修改資料(開訂單、改客戶),重新整理頁面即可。如果是請人改了程式,要關掉黑視窗、重跑 `啟動.bat`。

**Q:客戶下拉找不到人?**
A:先確認拼字;真的沒有就點「找不到?先去新增客戶」。

**Q:訂單金額怎麼算的?**
A:各列(數量 × 單價)加總(贈品不算錢)= 應收合計,這是**含稅**的金額。改品項後按「儲存」會重算。運費另外記,「店家吸收」不算進應收合計、「客戶付」才會自動加進應收合計。

---

**Q:一張訂單想整個作廢?**
A:訂單明細頁右上角有「刪除訂單」,會問一次確認,刪掉後連同品項、退款紀錄、總帳傳票都會一起清掉,**無法復原**。客人退貨又退款也是用這個。

**Q:勾了「已開發票」但發票號碼不給我存檔?**
A:這是故意設計的——開了發票就一定要有發票號碼,系統會擋下沒填號碼的存檔。真的還沒拿到號碼,先不要勾「已開發票」,等拿到號碼再回來勾、填上去、存檔。

**Q:黑視窗出現紅色錯誤?**
A:把整段訊息截圖或複製給維護人員。
