# 交付說明(給郡碩農創)

## 怎麼用

1. 收到的是一個資料夾 **`桂圓帳房`**(或壓縮檔,先解壓縮)。放到桌面或任何位置都可以。
2. 打開資料夾,**雙擊 `桂圓帳房.exe`**。
3. 會跳出一個黑色小視窗(寫著「桂圓帳房 已啟動」),接著自動開啟瀏覽器。
   - 沒自動開的話,自己開瀏覽器輸入:`http://127.0.0.1:8000`
4. 就在瀏覽器裡操作。
5. **用完後,關掉那個黑色小視窗** —— 程式就關閉了。

> 不用安裝 Python、不用網路、不用登入。所有資料都在你自己電腦裡。

---

## 資料存在哪裡

在 `桂圓帳房.exe` **同一個資料夾**裡:

| 檔案 / 資料夾 | 內容 |
|---|---|
| `guiyuan_ledger.db` | 你所有的資料(客戶、訂單、進貨、費用…)。**這一個檔案就是你的全部資料。** |
| `備份/` | 每天第一次開程式時,自動複製一份當天的資料庫進去,保留最近 30 份 |

**第一次打開**會自動建立一份「示範假資料」讓你試玩。要清空重來:關掉程式 → 刪掉 `guiyuan_ledger.db` → 再打開一次(又會是示範資料)。

---

## 備份 / 搬到新電腦

- **備份**:把整個 `桂圓帳房` 資料夾複製到隨身碟 / 雲端硬碟。最重要的是 `guiyuan_ledger.db`。
- **換電腦**:把整個 `桂圓帳房` 資料夾複製到新電腦,一樣雙擊 `桂圓帳房.exe`。資料會跟著走。
- **只想還原到某一天**:關掉程式 → 到 `備份/` 找到那天的檔 → 複製出來、改名成 `guiyuan_ledger.db` → 蓋掉原本的 → 重新打開。

---

## 常見狀況

| 狀況 | 處理 |
|---|---|
| 雙擊沒反應 / 瀏覽器沒開 | 手動開瀏覽器輸入 `http://127.0.0.1:8000` |
| 黑視窗一閃就不見 | 資料夾可能被防毒軟體擋。把 `桂圓帳房` 資料夾加到防毒白名單 |
| 顯示「可能已經在執行」 | 你之前開的還沒關。先把舊的黑視窗關掉,再雙擊一次 |
| Windows 跳出「保護您的電腦」藍色視窗 | 點「其他資訊」→「仍要執行」(這是因為程式沒有付費簽章,不是病毒) |
| 要多台電腦一起看 | 目前設計是單人單機。要共用要另外處理,先跟我們說 |

## 給開發 / 維護的人

- 原始碼:https://github.com/chihsuanwang/Jun-Shuo
- 改完程式碼 → 重跑 `打包.bat` → 把新的 `dist/桂圓帳房/` 交付。
- exe 不進版控(`.gitignore` 已排除 `app/dist/` `app/build/`)。
