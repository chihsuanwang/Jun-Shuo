# 桂圓帳房 · 營運流程 SOP

這份不是「畫面導覽」(那份是 [展示腳本.md](展示腳本.md) / [使用手冊.md](使用手冊.md),
照左側選單一頁一頁介紹功能)。**這份是「做生意的順序」**——照這個順序做,系統裡的數字才會
一步步疊出來,而不是東點一塊、西點一塊。第一次上手照這份走一遍;之後想查某個畫面怎麼
操作,查使用手冊.md 比較快。

全部截圖是 `seed.py` 產生的**示範假資料**,畫面長相跟真的操作一樣,只是數字是假的。

> 所有記帳動作(包含這份 SOP 提到的訂單、營運支出、固定資產)都可以從左上角
> **「＋ 記一筆(九宮格)」** 一次進入,卡片點進去就是原本這份 SOP 講的那些畫面——
> 這份 SOP 走的是業務發生的順序,九宮格是另一種「先想好要記哪一種再進去」的入口,
> 兩種殊途同歸,選你順手的用就好。

> **2026-10 起的做法:郡碩是「接單才跟小農買」的貿易公司**。沒有存貨,也沒有「進貨」「庫存」:
> 開一張訂單時,每個品項自己填成本,而且**接單當天就付錢給小農**,所以一張訂單就把
> 「客人欠我們多少」「這批貨的成本」「已經付給小農」一起記好,不用再另外登記付小農貨款。

---

## 整體邏輯:三個階段

| 階段 | 做什麼 | 做幾次 |
|---|---|---|
| **一、開店設定** | 商品與售價、銷售管道、客戶、既有設備 | 只做一次(之後有新品項/新客戶才補) |
| **二、日常營運循環** | 訂單(填成本、當天付小農)→ 出貨 → 收款 →(退貨 / 退款) | 每天 / 每筆重複 |
| **三、定期檢視** | 營運支出、財務健康、獲利報表、總帳、儀表板 | 每月 / 每季回頭看 |

**為什麼要照這個順序**:訂單要挑客戶、挑商品——客戶跟商品都還沒建好,訂單根本填不出來。
客戶要選主要銷售管道——管道也要先設好。所以「先設定、再營運、最後定期回顧」不是
選擇,是系統結構本身要求的順序。

---

## 第一階段:開店設定(只需要做一次)

### 1. 定價試算 —— 先抓成本、抓售價

**為什麼是第一步:** 還沒開始賣之前,要先知道「賣多少錢才不會虧」。這是一個純估算工具,
不會動到任何訂單或帳,可以放心試。

**點:** 左側「看數字 → 定價試算」

![定價試算](screenshots/manual/pricing.png)

**怎麼做:** 上面幾張卡分別是「共用」「龍眼鮮果」「龍眼乾」「龍眼肉」「蜂蜜」的成本參數
(人工、包材、運費…),填自己的真實數字 → 下面「龍眼鏈・成本一路串下去」會自動把上一階段
的成本轉進下一階段、算出可售成本、跟目前售價比出毛利率。改完按「儲存參數」留住這組數字。

**產出:** 算出來的「建議售價」,就是下一步要填進商品目錄的數字;「可售成本」可以當開單時填成本的參考。

---

### 2. 商品目錄 —— 把商品跟價格建起來

**為什麼現在做:** 上一步算好的售價,要填進這裡才會變成一個「真的可以拿來開訂單」
的商品。

**點:** 左側「設定一次的 → 商品目錄」

![商品目錄](screenshots/manual/products.png)

**示範新增:** 「＋新增商品」→ 品名(必填)、型態、產品線、內容量、計價單位、保存天數/條件、
原料成分 →「**售價**」(**含稅**)→ 存。**品項代碼**系統自動編(F001、F002…),不用填。

![新增商品](screenshots/manual/product-new.png)

**順手確認:** 一個規格建一個品項(例:300g 跟 500g 是兩個);之後編輯商品可以隨時改價。
**成本不在這裡填**,開訂單時每列自己填。

---

### 3. 銷售管道 —— 建立賣貨的通路

**為什麼現在做:** 客戶要掛在「哪個管道」底下(官網?LINE 社群?批發?),管道要先建好,
下一步建客戶時才選得到。

**點:** 左側「設定一次的 → 銷售管道」

![銷售管道](screenshots/manual/channels.png)

**示範新增:** 「＋新增管道」→ 代碼(必填,例:WEB)、名稱(必填)、分類、帳期(天)→ 存。

![新增管道](screenshots/manual/channel-new.png)

---

### 4. 客戶資料庫 —— 建立客戶

**為什麼是這裡才做:** 新增客戶時要選「主要銷售管道」(對到第 3 步),管道要先設好,客戶才建得完整。

**點:** 左側「設定一次的 → 客戶資料庫」

![客戶資料庫](screenshots/manual/customers.png)

**示範新增:** 「＋新增客戶」→ 名稱(必填)、電話、**客戶分類**(企業戶 / 個人戶)、**主要銷售管道**、
Email、聯絡人 → 下面「開單據 / 收件」填發票抬頭、收件地址 → 存。**客戶編號**系統自動編(例 C2026001)。
客戶不分級,開單一律帶商品目錄的售價。

![新增客戶](screenshots/manual/customer-new.png)

---

### 5. 固定資產(如果本來就有設備)

**為什麼放這裡:** 開始營運前先把既有的焙灶、機器建卡,折舊才會從正確的取得日開始算,
之後每月自動算進財務健康,也會自動記進總帳,不用手動記。沒有既有設備的話這步可以跳過,
之後買新設備再回來補。

**點:** 左側「設定一次的 → 固定資產」→「＋新增一台」

![新增固定資產](screenshots/manual/asset-new.png)

**怎麼做:** 填名稱、選類別、取得日、取得成本、進項稅額(沒有填 0)、付款帳戶(用選的)→ 存。
**使用年限用月填,最少 120 個月**(低於 120 存不進去),**殘值一律 0** 不用填。存檔後系統會自動記一筆「設備取得」分錄;之後每個月只要打開這頁,系統會順便把還沒
記過的折舊月份補齊,不用手動一筆一筆記。

## 第二階段:日常營運循環(每天 / 每筆訂單重複的事)

第一階段的設定做完後,平常會不斷重複下面這個循環:**客人下單(當天付錢給小農)→ 出貨 → 收款
→(偶爾要處理退貨 / 退款)**。這個順序就是一筆生意實際發生的順序。

### 6. 新增訂單 —— 客人下單(循環的起點)

**為什麼現在才填得出來:** 訂單要挑客戶(第 4 步建的)、挑商品(第 2 步建的,單價會自動帶出售價)
——這正是為什麼客戶、商品要先設定好的原因。

**點:** 左側「每天做的 → 訂單」→「＋新增訂單」

**怎麼做:** 打客戶名字搜尋 → 點選 → 品項選商品(單價自動帶)→ 填數量 → **每列填「成本」**
(這列的貨跟小農買花多少錢)→ 選「成本付給小農的帳戶」→ 運費(跟客人收的才填)→
**收款**:還沒收到選「應收帳款」,當場收齊選收到哪個帳戶 → 有開發票記得勾「已開發票」並填發票號碼
(勾了沒填不給存檔)→ **填「銷項稅額」**(售價含稅,這張單含了多少稅自己填,系統不算)→ 存檔。

![新增訂單](screenshots/manual/order-new.png)

存檔的同時,系統會自動記好:客人欠我們多少(含稅)、這批貨的採購成本、當天已經付錢給小農。
不用另外去記進貨或付小農貨款。

**如果是一批訂單(例如 Google 表單收單、或客人給一份 Excel 名單):** 不用一筆一筆手動開,
訂單清單頁右上角「匯入」,不確定欄位怎麼打可以先點「下載範本」,上傳 `.csv`/`.xlsx`,
系統會先給你看預覽、確認無誤才會真的建單,細節看 [使用手冊.md](使用手冊.md) 第五節。
**匯入的訂單銷項稅額是 0,匯完要一張張補填。**

---

### 7. 出貨作業 —— 揀貨、貼標、出貨

**為什麼在訂單之後:** 訂單確認了,才知道要出哪些貨、印哪些標籤。

**點:** 左側「出貨 / 退貨 → 出貨作業」

![出貨作業](screenshots/manual/shipping.png)

**怎麼做:** 「揀貨單」列出要出的訂單 + 彙總備貨量,可列印;「出貨標籤 / 送貨單」每張訂單
一張卡;「食品標示」選商品 + 份數就能產生貼在包裝上的標示。

---

### 8. 收款 / 標記已出貨

**為什麼放這裡:** 貨出了、錢收了,要把狀態更新,儀表板跟財務健康的數字才會跟著動。

**收款:** 左側「每天做的 → 應收帳款(收款)」,勾選收到錢的那幾張訂單 → 按「收款」→
選收到哪個帳戶、收款日。收款一定一次收齊,金額 = 應收合計。

![應收帳款](screenshots/manual/receivables.png)

**出貨:** 訂單明細頁,先在「出貨」卡選出貨方式 → 按「標記已出貨」。

![訂單明細](screenshots/manual/order-detail.png)

**要注意:** 收款跟出貨互不卡——訂單可以照樣出貨,不管有沒有收到錢(配合貨到付款、月結批發的實況)。
收款的同時,系統會在總帳補一筆收款分錄,不用你管。

---

### 9. 退貨 / 退款(有狀況才做)

**為什麼是選擇性的一步:** 不是每筆訂單都會發生,但客訴、退貨隨時可能出現,順序上接在
「已出貨」之後。

**怎麼做:** 先分清楚是哪一種:

| 情況 | 怎麼做 |
|---|---|
| **退貨又退款** | 直接在訂單頁按「**刪除訂單**」,總帳會一起刪掉 |
| **只退款、不退貨** | 訂單頁最下方「退款 / 退回小農」,類型選「**退款**」,金額填退給客人多少、錢從哪個帳戶退(不管多少都算其他支出) |
| **退貨但不退款** | 同上,類型選「**退回小農**」,金額填小農退回多少、退回哪個帳戶、扣哪一項採購成本(畫面上有這張訂單的成本合計可以參考) |

**點:** 左側「出貨 / 退貨 → 退款 / 退回小農」看所有紀錄

![退款 / 退回小農清單](screenshots/manual/returns.png)

## 第三階段:定期檢視(每月 / 每季回頭看)

日常循環在跑的同時,有幾件事要**定期**(通常是每月)回來做一次,系統才看得出真實的損益。

### 10. 營運支出 —— 每筆照發票記

**為什麼要「主動」記:** 訂單相關的營收 / 成本系統自動算,但薪資、房租、運費、包材這些花費
不會自己跑進系統,要每筆記進來,淡季也要記,不然損益會失真。

**點:** 左側「每天做的 → 營運支出」→「＋新增一筆」

![營運支出清單](screenshots/manual/expenses-list.png)

**怎麼做:** 一頁填完——日期、備註 → **VD 費用**:選科目、填發票金額(含稅實付)→
**C 付款帳戶** → **G 進項稅額**:稅額、憑證類型、發票號碼(選發票就必填)→ 看一眼下面的分錄預覽 → 儲存。
系統會自動算「費用 = 發票金額 − 進項稅額」。一次性大支出不再分月攤提。

![新增營運支出](screenshots/manual/expense-new.png)

利息、所得稅這類不屬於營運的支出,到「其他支出」記,填法一樣。

---

### 11. 財務健康 —— 看月損益

**點:** 左側「看數字 → 財務健康」

![財務健康](screenshots/manual/finance.png)

**怎麼看:** 月稅前利潤趨勢(綠賺紅虧)、累積稅前利潤、毛利率趨勢;點某個月看完整損益明細。
營收都是**扣掉銷項稅額**之後的數字。

---

### 12. 獲利報表 —— 拆更細看

**點:** 左側「看數字 → 獲利報表」,3 個頁籤:

| 頁籤 | 回答什麼問題 |
|---|---|
| 獲利分析 | 哪個商品/哪個通路賺?客戶回不回購?本季誰是 Top 客戶? |
| 收款帳齡 | 還沒收到的貨款,卡在誰那裡多久了?最近誰又收回來了? |
| 跨產季比較 | 今年比去年同期好不好? |

![收款帳齡](screenshots/manual/reports-aging.png)

---

### 13. 總帳 / 財務報表 / 科目明細(比較深入,同事在看的居多)

**為什麼放在這裡:** 前面每一步存檔,系統都已經自動記好分錄,這幾頁是把記好的東西整理
成不同角度可以核對:

| 頁面 | 看什麼 |
|---|---|
| **總帳** | 所有分錄一行一筆,預設依傳票號碼由小到大,可以點標題排序、篩選;要刪除就勾選,同一張傳票整張一起刪 |
| **財務報表** | 給同事報稅用的試算表 / 資產負債表 / 綜合損益表,固定用西曆年(1~12 月)。試算表列出所有科目,可以下載 |
| **銀行帳戶明細** | 現金 / 各銀行帳戶各自的進出流水 + 累計餘額 |
| **科目明細** | 選一個會計科目,看它每一筆交易跟累計餘額 |
| **銀行帳戶 / 會計科目設定** | 科目的來源,可以新增、改名、停用 |

![總帳](screenshots/manual/ledger.png)

平常不用特別看這幾頁,想深入了解記帳邏輯、科目對照,看 [功能手冊.md](功能手冊.md)。

**全鏈路毛利分析**(選單「看數字」)不算在這幾頁裡——它是**估算工具,不是真的帳**,
把付給小農的成本拆解成「供應端大概賺多少、公司大概賺多少」,給自己決策參考用,
不影響總帳或財務報表的任何數字。想用的話直接進去看,不用照順序來,
細節看 [使用手冊.md](使用手冊.md) 第十五節。

---

### 14. 儀表板 —— 平常隨時看的總覽

**為什麼放在最後:** 前面所有步驟的資料建好、循環跑起來之後,首頁儀表板才會有東西可看——
它其實是把所有階段的結果彙總成一頁。設定好之後,這頁會變成平常**打開系統第一眼看的畫面**。

![儀表板](screenshots/manual/dashboard.png)

**看什麼:** 頂端「需要注意」的待辦提醒、4 個 KPI(營收/稅前利潤/毛利率/未收貨款)、
本產季損益簡表、產季目標進度、月營收趨勢圖。

**回頭校正:** 如果發現某個商品毛利率一直不理想,回到第 1 步的「定價試算」調整參數、
回第 2 步改商品售價——這就是為什麼定價試算跟商品目錄放在最前面,因為之後會一直回來調。

## 一張圖看完整順序

```
【一、開店設定,只做一次】
  定價試算 → 商品目錄(售價)→ 銷售管道 → 客戶資料庫 → (固定資產)
                                                          │
                                                          ▼
【二、日常循環,每天 / 每筆重複】
  新增訂單(填成本、當天付小農、記得填稅額)→ 出貨作業 → 應收帳款收款 / 標記已出貨 → (退貨 / 退款)
                                                          │
                                                          ▼
【三、定期檢視,每月 / 每季】
  營運支出 → 財務健康 → 獲利報表 → 總帳 / 財務報表 / 科目明細 → 儀表板(回頭校正定價,調整循環)
                            (全鏈路毛利分析:想用隨時進去看,不用照順序)
```
