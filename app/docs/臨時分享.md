# 臨時分享(cloudflared 快速通道)

> 用途:**短時間(1~2 小時)讓同仁從自己的手機 / 電腦連進來看**,不用安裝、不用部署、不用改程式。
> 適用前提:**畫面上都是示範假資料**。要長期 / 多人 / 真實客戶資料 → 走「上雲」回合(加登入 + 正式部署),見 [開發路線.md](開發路線.md)。
>
> 背景:免安裝 exe 在開了「智慧型應用程式控制(SAC)」的 Windows 11 上會被硬擋(未簽章),
> 臨時要給人看就用這個方式繞過。

---

## 一、只要裝一次:cloudflared

PowerShell(有網路):

```powershell
winget install --id Cloudflare.cloudflared
```

裝完**關掉 PowerShell、重開一個新視窗**(PATH 才會認得 `cloudflared`)。
cloudflared 由 Cloudflare 簽章,SAC 不會擋。

---

## 二、每次要分享時(3 個視窗都要開著)

### 1. 把 app 跑起來
`app` 目錄雙擊 `啟動.bat` → 瀏覽器能開 `http://127.0.0.1:8000` 就 OK。

### 2. 另開一個新的 PowerShell,執行:

```powershell
cloudflared tunnel --url http://localhost:8000
```

若說「不是可辨識的指令」→ 用完整路徑,**前面要加 `&`**:

```powershell
& "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --url http://localhost:8000
```

### 3. 找網址

輸出裡(靠近開頭、`SUMMARY: Environment is healthy` 上面幾行)會有一個框:

```
+--------------------------------------------------------------+
|  Your quick Tunnel has been created! Visit it at ...         |
|  https://xxxx-xxxx-xxxx.trycloudflare.com                    |
+--------------------------------------------------------------+
```

把 `https://....trycloudflare.com` 傳給同仁,他們瀏覽器直接開,什麼都不用裝。
看到 `Registered tunnel connection ... location=tpe01` = 已連上台北節點。

### 4. 結束

在 cloudflared 那個視窗按 **Ctrl+C**(或關視窗)→ 網址立刻失效。

---

## 注意

- 網址是**隨機的、每次不同**、關掉就沒了 —— 下次要分享得重跑、重傳新網址。
- 你的電腦、`啟動.bat`、cloudflared **三個都要保持開著**,同仁才連得到。電腦休眠也會斷。
- 這是**公開網址、沒有密碼** —— 只私下傳給同仁,別貼到公開群組;只放假資料。
- 撐 1~2 小時沒問題;長時間掛著 Cloudflare 可能會斷線。

## 疑難

| 狀況 | 處理 |
|---|---|
| 往上捲找不到網址(被洗掉) | 該視窗 Ctrl+C,再執行一次,網址會在最前面重印 |
| 同仁開網址是空白 / 502 | 確認 `啟動.bat` 那個視窗還在跑、`http://127.0.0.1:8000` 本機開得起來 |
| `cloudflared` 找不到 | 開新的 PowerShell 視窗;或用第二節的完整路徑寫法 |
