## 1. 儀表板(首頁)

**點:** 左上「儀表板」

![儀表板](screenshots/01-dashboard.png)

**應該看到:**
- 頂端「需要注意」幾個橘色標籤(貨款逾期未收、超過 3 天還沒出貨、破損/遺失待處理、待確認資料、庫存偏低)
- 4 個 KPI 卡:本產季營收(實收)、本產季稅前利潤、毛利率、還沒收到的貨款
- 「本產季至今損益簡表」卡:營收 → −銷貨退回與折讓 → −銷貨成本 → 毛利 → −運費 → −營運費用 → 稅前利潤
- 「產季目標 & 進度」卡:目標營收、實際營收、達成率、已出貨月數、依速度預估季末、損益兩平需營收
- 「月營收 / 毛利趨勢」圖(滑鼠移上去看各月)

**怎麼講:** 「一頁看完:這季賣多少、扣掉所有開銷剩多少、目標達成沒。」

**要注意:** 剛開季(4 月)或旺季還沒到的月份,「稅前利潤」看起來會是一大包負的——這是因為
營運費用(人事、田間管理…)每個月都要付,但銷售旺季通常集中在後幾個月。這不是算錯,是「前期
投入還沒被賣出去的量補回來」,demo 時可以順帶說明,不然數字看起來會嚇人。

**順手確認:** 右上「產季」切換,數字要跟著變;橘色標籤點下去會跳到對應頁。

## 2. 開一張訂單(每天做的核心)

**點:** 左側「每天做的 → 訂單」→「＋ 新增訂單」

**示範:** 打客戶名字搜尋 → 點選 → 品項選一個商品(單價會依客戶分級自動帶)→ 填數量 → 存檔

![新增訂單](screenshots/03-order-new.png)

存檔後進訂單明細,依序示範「標記已收款」(要先在下面「收款」卡填實收金額)、「標記已出貨」:

![訂單明細,已收款已出貨](screenshots/05-order-paid-shipped.png)

**怎麼講:** 「賣出去就開一張訂單,收到錢按『標記已收款』,出貨按『標記已出貨』。儀表板跟財務
健康的數字都是照這裡自動算的,不用另外記帳。」

**順手確認:** 訂單清單可篩「貨款逾期 / 未收款 / 超過 3 天未出貨」、可搜尋單號或客戶;
右上可匯出 CSV。

![訂單清單](screenshots/02-orders-list.png)

## 3. 記一筆進貨

**點:** 「每天做的 → 進貨」→「＋ 記一筆進貨」

**示範:** 日期、供應商(下拉,沒有可先「新增供應商」)、類別(原料/包材/委外加工/設備…)、
金額 → 存。勾「這是設備」的話之後可以在固定資產頁「建卡」提折舊。

![新增進貨](screenshots/07-purchase-new.png)

**怎麼講:** 「買鮮果、包材、木柴、委外加工都記這裡。目前先當單純登錄用,商品賣出去要算多少
成本,是在『商品目錄』裡個別商品填的『單位成本』。」

**順手確認:** 進貨清單上方可依月份篩;標「設備」的那筆右邊有「建卡 →」連結。

![進貨清單](screenshots/06-purchases-list.png)

## 4. 營運費用(每月要維護的)

**點:** 左側「每天做的 → 營運費用」→「＋ 新增一筆」

**示範:** 月份、項目(下拉,例如「直接人工」「田間管理」「研發」)、金額、一次性大支出才填
「攤提月數」→ 存 → 回列表看到。

![營運費用清單](screenshots/08-expenses-list.png)

**怎麼講:** 「營收、成本、毛利是訂單自動算的;營運費用要你每月填一次,淡季也要填,才看得出
真實的損益。研發那種一次花一大筆的,填『攤提月數』它會自己分月攤,不會某個月爆一筆。」

## 5. 財務健康

**點:** 「看數字 → 財務健康」

![財務健康](screenshots/09-finance.png)

**應該看到:** 月稅前利潤趨勢(綠=賺 紅=虧)、累積稅前利潤、毛利率趨勢、選定月份的完整損益
明細、各產季合計表。

**順手確認:**
- 趨勢圖**點某個月** → 下面損益明細列出那月的完整損益;勾「多選」再點幾個月 → 看合計
- 淡月是紅的 —— 沒收入還是要付固定成本 + 折舊 + 研發攤提

**怎麼講:** 「這頁看『這個月/這幾個月賺不賺』,跟儀表板算法一致,只是可以拆到月份細看。」

## 8. 其餘頁面(快速帶過)

- **客戶資料庫** —— 清單 + 搜尋(可搜電話)→ 點進客戶明細(基本資料、地址、往來紀錄、
  累計消費)→ 編輯 / 合併重複客戶
- **商品目錄** —— 每個品項規格 + 各客戶分級定價
- **供應商** —— 名稱、統編、類別、電話
- **銷售管道** —— 官網 / LINE 社群 / 批發,可設抽成、帳期
- **庫存** —— 每個商品現有幾包、低於警戒量會標出來
- **出貨作業** —— 揀貨單 / 出貨標籤 / 食品標示,可列印;右上「物流異常處理」
- **退貨 / 折讓** —— 訂單頁一鍵「整筆退單」,這頁看全部退貨/折讓紀錄
- **定價試算** —— 給同仁抓成本抓售價用的估算工具,純試算不碰帳

需要的話,這幾頁的截圖都在 `screenshots/` 資料夾裡(13~17、19~21 號檔),demo 前想再確認
畫面長相可以直接開來看,這裡就不逐一放圖了。

## 9. 收尾:要跟家易確認 / 請他去問的事

**營運事實(他答得出):**
- 設備清單:每台大概買價、什麼時候買的、有沒有政府補助
- 申報表「研發費」的內容是什麼(新品?委外?其實是設備?)
- 「薪資支出」有沒有包含他自己下田 / 顧焙灶 / 剝肉的工
- 蜂蜜是自己養蜂採,還是收購生蜜回來瓶裝?
- 果園一年的管理開銷大概多少(施肥、疏果、防治、灌溉、人工)

**跟他說清楚:**
- 這些數字全是假的,換成真資料要一起做「切轉日盤點」(現有庫存、設備、現金、應收應付)
- 目前系統不處理報稅,只算「賣出後實際收到多少錢」——如果之後真的需要報稅底稿,是另一個
  獨立的專案
