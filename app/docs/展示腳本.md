# 展示腳本(給郡碩農創 demo 前自己先跑一遍)

用途:demo 前照這份走一次 —— ①每個功能都點過確認正常、②對一下數字、③練一下怎麼講。
全部是 `seed.py` 產生的**示範假資料**,重點是「結構對不對、能不能回答老闆的問題」,不是數字本身。

啟動:關掉舊的黑視窗 → 雙擊 `啟動.bat` → 瀏覽器開 http://127.0.0.1:8000

---

## 0. 一句開場(給家易)

> 「這是拿假資料做的樣子。重點不是這些數字,是想跟你確認:①這套『怎麼分類、怎麼算』對不對;
> ②有沒有漏掉你會在意的成本;③如果你想看到這個程度,我們就一起把你的真資料整理進來。」

## 1. 儀表板(首頁)

**點:** 左上「儀表板」

**應該看到:**
- 頂端「需要注意」幾個橘色標籤(逾期未收、待出貨、快到期…)
- 4 個 KPI:本產季營收(約 77 萬)、稅前利潤(約 +1.8 萬,小賺)、毛利率(約 72%)、還沒收到的貨款
- 「本產季損益(濃縮版)」卡:營收 → −銷貨成本 → 毛利 → −通路抽成 → ±運費 → −營運費用 → 稅前利潤
- 「產季目標 & 進度」卡:目標 50 萬、已達標、損益兩平線
- **「各產品線賺不賺」卡**:龍眼肉賺、龍眼乾虧、蜂蜜小虧、合計接近打平
- 「月營收 / 毛利趨勢」圖(滑鼠移上去看各月)

**怎麼講:** 「一頁看完:這季賣多少、扣掉所有開銷剩多少、目標達成沒、哪條產品線在賺。」

**順手確認:** 右上「產季」切 2024 / 2025 / 全部,數字要跟著變;橘色標籤點下去會跳到對應頁。

---

## 2. 各產品線賺不賺 ★ 這頁最重要

**點:** 左側「看數字 → 各產品線賺不賺」

**應該看到(2025 產季):**
| | 龍眼鮮果 | 龍眼乾 | 龍眼肉 | 蜂蜜 |
|---|---|---|---|---|
| 營收 | 很小 | ~28 萬 | ~44 萬 | ~2.8 萬 |
| 線利潤 | 小賺 | **約 −13 萬** | **約 +14 萬** | 約 −1.5 萬 |

**怎麼講:**
- 「**龍眼肉是金雞母** —— 售價高、材料成本低,32% 利潤率。」
- 「**龍眼乾量大但被拖垮** —— 營收不小,但田間管理 + 採收焙製的人工重,再加上分攤到的共同費用,就變負的。這就是『有量沒利』。」
- 「**蜂蜜還在起步** —— 量太小,撐不起分攤的共同費用,先小虧。」
- 「中間『線貢獻』是正的、但『線利潤』是負的 → 代表這條線本身有賺,是共同費用(研發、老闆的時間、行銷)壓下去的。」

**順手確認:**
- 上方「共同費用分攤」切 依營收 / 依銷量 / 依直接成本 → 數字會變（沒有絕對正確,重點是不管怎麼分哪條線站不站得住）
- 「產季」切 2024 → 整組數字換一批
- 最下面有一段口徑說明(蜂蜜用進貨估材料、和財務健康稅前利潤的小差異)

## 3. 財務健康

**點:** 「看數字 → 財務健康」

**應該看到:** 月稅前利潤趨勢(綠=賺 紅=虧)、累積稅前利潤、毛利率趨勢、各產季合計表。

**順手確認:**
- 趨勢圖**點某個月** → 下面「損益明細」列出那月的完整損益;勾「多選」再點幾個月 → 看合計
- 淡月(4–8 月)是紅的 —— 沒收入還是要付固定成本 + 折舊 + 研發攤提
- 右上「維護營運費用」→「＋ 新增一筆」→ 示範填一筆:月份、項目(選「直接人工」)、**歸哪條產品線**、金額、（一次性大支出才填）**攤提月數** → 存 → 回列表看到

**怎麼講:** 「營收、成本、毛利是訂單自動算的;營運費用要你每月填一次。研發那種一次花一大筆的,填『攤提月數』它會自己分月攤,不會某個月爆一筆。」

---

## 4. 開一張訂單(核心日常)

**點:** 「每天做的 → 訂單」→「＋ 新增訂單」

**示範:** 挑一個客戶 → 加 1–2 個品項、填數量(單價會依客戶分級自動帶)→ 存 → 進訂單明細 → 按「標記已收款」「標記已出貨」

**順手確認:** 訂單清單可篩「貨款逾期 / 未收款 / 超過 3 天未出貨」;右上可匯出 CSV。

---

## 5. 記一筆進貨

**點:** 「每天做的 → 進貨」→「＋ 記一筆進貨」

**示範:** 日期、供應商(下拉,沒有可先「新增供應商」)、類別(原料 / 包材…)、**歸哪條產品線 或 共同**、未稅金額、稅額 → 存

**怎麼講:** 「買鮮果、包材、木柴、委外加工都記這裡。每筆標歸哪條線,之後算『哪條線賺不賺』才分得出來。報稅要的稅額 / 憑證欄不確定可先留白。」

**順手確認:** 上方可依「產品線 / 月份」篩;上面兩格顯示未稅合計、可扣抵進項稅額。

---

## 6. 固定資產 + 折舊

**點:** 「設定一次的 → 固定資產」

**應該看到:** 5 台(智慧柴焙灶〔含 10 萬政府補助〕、剝殼機、搖蜜機、冷藏庫、貨車);上方四格:成本、累計折舊、帳面淨值、每月折舊。

**示範新增:** 「＋ 新增一台」→ 填名稱、**選類別(會自動帶耐用年數)**、成本、補助 →「殘值」留白(自動算)→ 下面即時顯示每年 / 每月折舊 → 存

**怎麼講:** 「焙灶、機器、貨車這種不是一次性費用,要逐年提折舊。建卡後系統每月自動把折舊算進財務健康,不用手動記。有政府補助的,補助那部分不提折舊。」

**順手確認:** 回「進貨」頁,標了「設備」的那筆右邊有「建卡 →」,點了會把金額 / 日期帶進來。

## 7. 產品線設定

**點:** 「設定一次的 → 產品線」

**應該看到:** 事業別(龍眼 / 蜂蜜)→ 產品線(龍眼鮮果 / 乾 / 肉 / 蜂蜜)→ 底下掛的商品。

**怎麼講:** 「所有『哪條線賺不賺』『報稅應稅免稅』都掛在這個三層結構上。稅別現在全是『待確認』—— 這要去問國稅局:你的龍眼乾、龍眼肉、蜂蜜各算免稅初級農產、還是應稅加工食品。」

**順手確認:** 改某個產品線的「稅別」下拉、改名 → 存。

## 8. 其餘頁面(快速帶過)

- **客戶資料庫** —— 清單 + 搜尋(可搜電話)→ 客戶明細(往來紀錄、累計消費)→ 編輯 / 合併重複
- **商品目錄** —— 每個品項規格 + 各分級定價
- **焙製批次** —— 每窯的產出 / 已出 / 剩餘 / 到期日 / 剩餘貨值
- **庫存** —— 每個商品現有幾包、快到期、超賣警示
- **銷售管道** —— 官網 / 市集 / 批發 / 抽成平台 及各自抽成
- **出貨作業** —— 揀貨單 / 出貨標籤 / 食品標示,可列印;右上「物流異常處理」
- **獲利報表** —— 3 分頁:獲利分析(依商品 / 通路 + 品項佔比 + 新客回頭 + Top 客戶)、收款帳齡、跨產季比較

## 9. 收尾:要跟家易確認 / 請他去問的事

**營運事實(他答得出):**
- 設備清單:每台大概買價、什麼時候買的、有沒有政府補助
- 申報表「研發費」的內容是什麼(新品?委外?其實是設備?)
- 「薪資支出」有沒有包含他自己下田 / 顧焙灶 / 剝肉的工
- 蜂蜜是自己養蜂採,還是收購生蜜回來瓶裝?
- 果園一年的管理開銷大概多少(施肥、疏果、防治、灌溉、人工)

**要去問國稅局南投分局:**
- 龍眼鮮果 / 龍眼乾 / 龍眼肉 / 蜂蜜,各自算免稅初級農產、還是應稅加工食品?

**跟他說清楚:**
- 這些數字全是假的,換成真資料要一起做「切轉日盤點」(現有庫存、設備、現金、應收應付、留抵稅額)
- 申報表那筆「兌換益 100 多萬」很奇怪,我們新制度不承接,要確認那到底是什麼
