- [ ] **另一台電腦 `git pull` 之後,要先重灌本機資料庫**:這一輪改了資料表結構(拿掉進貨 / 庫存 / 供應商,
      加了銷項稅額、付小農貨款、訂單成本欄位),舊的 `guiyuan_ledger.db` 不能直接用。
      在 `app` 資料夾執行 `.venv\Scripts\python seed.py --force`(會清空、灌回示範資料)。
      啟動時如果看到「資料庫還是改版前的結構」的警告,就是還沒重灌。
