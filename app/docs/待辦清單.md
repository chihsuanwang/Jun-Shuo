## 換電腦接手時,先做這件事

- [ ] **`git pull` 之後,要先重灌本機資料庫**:這一輪又改了資料表結構(會計科目表、訂單成本、
      資本異動、帳務調整多行…),舊的 `guiyuan_ledger.db` 不要直接用。
      在 `app` 資料夾執行 `.venv\Scripts\python seed.py --force`(會清空、灌回示範資料)。
      (舊資料庫打開時 `migrate_db()` 會盡量自動補欄位 / 換表,但示範階段直接重灌最乾淨。)
- [ ] 先看 [工作日誌.md](工作日誌.md) 最後一段「2026-10-17 帶回家交接」,知道這一輪改了什麼。

## 要你決定時間的

- [ ] **上傳 GitHub**(要你說「上傳」才做)。
- [ ] **更新 Render 正式網站**:
  1. 到 Render 按 **Manual Deploy → Deploy latest commit**(Auto-Deploy 已關,push 不會自動更新)。
  2. 這次資料表結構有改,**網站上的資料庫要重建**:刪掉 `/data/guiyuan_ledger.db` 再重啟,
     `ensure_db()` 會自動建一個新的。Shell 連不上的話,照 [工作日誌.md](工作日誌.md) 2026-10-02
     「Start Command 暫時切換」的做法。同仁試用的資料不保留(使用者 2026-10-08 確認)。
  3. 要給同仁空白的資料庫就用 `seed.py --empty`(會計科目表會自動建好),不要用示範資料。
  4. 更新時網站會斷線一兩分鐘,挑同仁沒在用的時間。
