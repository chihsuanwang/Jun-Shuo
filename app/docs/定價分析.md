# 定價分析(單位成本 → 建議售價)

## 二、共用基礎:單位鮮果成本

龍眼三產品的起點都是「一台斤鮮果值多少錢」。

```
單位鮮果成本 = (全年田間管理費用 + 採收工資) ÷ 全年鮮果總產量
```

| 項目 | 假設值(待填) | 說明 |
|---|---:|---|
| 全年田間管理(修枝 / 施肥 / 除草 / 灌溉 / 防治 / 疏果 + 人工) | 180,000 | 全年,不分月 |
| 採收工資(9 月) | 30,000 | |
| 全年鮮果總產量(台斤) | 7,000 | 看天,建議用近 3 年平均 |
| **→ 單位鮮果成本** | **$30 / 台斤** | (180,000 + 30,000) ÷ 7,000 |

鮮果去向:一部分直接當「龍眼鮮果」賣,其餘投入焙製。**田間管理按各產品耗用的鮮果台斤數分攤**。

## 三、各產品成本建構表(單位:1 個銷售單位)

### 龍眼鮮果 · 台斤(現售價 $80)

| | 假設值 | 算式 |
|---|---:|---|
| 鮮果成本 | 30 | 1 台斤 × $30 |
| 分級挑選工 | 5 | |
| 包材(簡易) | 3 | |
| 損耗(保鮮期僅 ~10 天) | 6 | 抓 15% |
| **= 單位製造成本** | **44** | |
| + 分攤共同費用 | 8 | |
| **= 單位總成本** | **52** | |
| 目標毛利率 40% → **建議售價** | **87** | 52 ÷ (1 − 0.40) |
| 現售 $80 → **實際毛利率** | **35%** | (80 − 52) ÷ 80 |

### 龍眼乾 · 300g/包(現售價 $175)

| | 假設值 | 算式 |
|---|---:|---|
| 鮮果投入 | 57 | ~1.9 台斤鮮果 × $30 |
| 焙製燃料(柴) | 8 | |
| 顧焙灶工 | 15 | 一爐工資 ÷ 一爐產出包數 |
| 去殼 / 篩選工 | 8 | |
| 焙灶折舊 | 5 | ($120,000 ÷ 5 年 ÷ 12) ÷ 當月產量 |
| 焙製損耗 | 3 | 抓 3% |
| 包材(夾鏈袋) | 12 | |
| **= 單位製造成本** | **108** | ← 可填進「批次單位成本」的數(若人工另走營運費用,這裡就不含顧爐 / 篩選工) |
| + 分攤共同費用 | 25 | |
| **= 單位總成本** | **133** | |
| 目標毛利率 40% → **建議售價** | **222** | |
| 現售 $175 → **實際毛利率** | **24%** | 偏低,離目標有距離 |

> 禮盒(300g×2,現售 $350)= 2 × 單位成本 + 禮盒盒 / 提袋 + 包裝工,再重算。

### 龍眼肉 · 600g 罐(現售價 $600)

從帶殼桂圓乾再加工,**剝殼去核純手工,是成本關鍵**。

| | 假設值 | 算式 |
|---|---:|---|
| 桂圓乾原料(不含乾的包材) | 300 | ~等量帶殼桂圓乾製造成本 |
| **剝殼去核工** | 270 | **1.5 小時 × $180 / 小時**(← 務必實測工時) |
| 剝肉損耗(殼 + 核佔重) | 30 | |
| 包材(罐) | 30 | |
| **= 單位製造成本** | **630** | |
| + 分攤共同費用 | 40 | |
| **= 單位總成本** | **670** | |
| 現售 $600 → **實際毛利率** | **−12%** | **可能虧本** |

> ⚠️ 剝肉工時只要抓 1.0 或 2.0 小時,結論就從「小賺」翻到「大虧」。**這格一定要拿碼表實測。**
> 這也是「各產品線賺不賺」頁(用營運費用粗估)和這份(用工時細估)可能不一致的地方 —— 以實測為準。

### 蜂蜜 · 420g 罐(現售價 $420)

| | 假設值 | 算式 |
|---|---:|---|
| 蜂群飼養(糖 / 藥 / 箱材,全年)分攤 | 200 | 全年飼養費 ÷ 全年產罐數 |
| 採蜜 / 搖蜜 / 濾蜜 / 裝罐工 | 40 | |
| 蜂箱 / 搖蜜機折舊 | 11 | ($20,000 ÷ 5 ÷ 12) ÷ 當月產量 |
| 玻璃罐 420g | 25 | |
| **= 單位製造成本** | **276** | |
| + 分攤共同費用 | 30 | |
| **= 單位總成本** | **306** | |
| 目標毛利率 40% → **建議售價** | **460** | |
| 現售 $420 → **實際毛利率** | **27%** | |

> 蜜源是自然採集(龍眼花 / 荔枝花期),無花源成本,但產量看天、波動大 → 飼養費務必除以**多年平均產量**,不要用豐收年。

## 四、分攤方法

| 要分攤的 | 分攤基準 |
|---|---|
| 田間管理 | 各產品耗用的**鮮果台斤數** |
| 焙灶折舊、顧爐工(若按爐算) | 當期**產出包數** |
| 蜂群飼養、搖蜜機折舊 | 當期**產出罐數** |
| 共同費用(行銷 / 管理人事 / 研發攤提 / 驗證費 / 平台維運) | 營收 or 產量 or 直接成本 —— 和「各產品線賺不賺」頁的「分攤基準」下拉一致,建議先用**營收** |

**老闆自己的工**(下田 / 顧爐 / 剝肉):估算時要按**市價設一個時薪**算進直接人工,即使他沒領薪水(這是「管理調整值」,不影響帳載)。

## 五、怎麼用這份的結果

1. **填「批次單位成本」**:龍眼乾 / 龍眼肉每批的「單位製造成本」欄,用這裡算出的數(先定好規則:批次成本只放材料+製費、人工另走營運費用;或全含)。
2. **對照現售價**:實際毛利率 < 目標 → 要嘛調價、要嘛降成本、要嘛這條線縮量。
3. **決定敢不敢擴**:某條線單位總成本穩定 < 售價一大截,才有本錢擴產。
4. **不進帳本**:這裡的工時 × 時薪、老闆的工按市價 —— 都只在這份試算,不寫回營運費用 / 訂單。
